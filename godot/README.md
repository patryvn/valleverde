# Valle de Cernego — prototipo Godot

Este proyecto es independiente de la aplicación Android Java existente.

## Abrir
En Godot 4.7.2, pulsa **Importar**, selecciona la carpeta `godot` y abre `project.godot`.

## Controles iniciales
- WASD: moverse.
- Botón derecho + ratón: girar cámara.
- E: recoger recursos o construir en el solar.

## Estado
Prototipo inicial de escena 3D con terreno, árboles, recursos, personaje provisional y casa construible. Aún no es la migración completa ni una APK Android. Los modelos son primitivas temporales y deben sustituirse por modelos 3D con licencia adecuada.
